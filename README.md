Welcome to the official repository for the **Applied AI Automation & MCP** course. This repository contains the presentation summaries, open-source code, and practical labs for the 17-unit curriculum designed and instructed by **Mahmoud Hussien Mohamed**.

## 📖 Course Overview
This course bridges the gap between traditional software engineering and modern AI architecture. It is designed to take students from building deterministic, rule-based automation scripts to designing and deploying dynamic, reasoning AI agents using the **Model Context Protocol (MCP)**.

### Core Objectives
- Understand the foundational architecture of LLMs, tokens, and embeddings.
- Master advanced prompt engineering for deterministic, programmatic outputs.
- Build custom **Retrieval-Augmented Generation (RAG)** pipelines.
- Develop autonomous agents using ReAct and Chain of Thought (CoT) architectures.
- Implement **Model Context Protocol (MCP)** servers for tool integration.
- Deploy multi-agent systems via FastAPI and serverless architectures.

---

## 🗂️ Repository Structure

The repository is organized into five major phases. Each folder contains the `Core Concepts` and `Applied Lab` materials relevant to that stage of the course.

### Phase 1: AI & LLM Foundations
Foundational concepts covering automation theory, tokenomics, and structured prompt engineering.

### Phase 2: Data & Core Agents
Technical implementation of RAG pipelines, vector databases, and the core agent reasoning loop.

### Phase 3: Applied Automation
Practical integration with automation platforms and system-level Python scripting.

### Phase 4: Model Context Protocol (MCP) Ecosystem
Deep dive into the MCP standard, building custom servers, and exposing local tools to AI clients.

### Phase 5: Advanced Systems & Deployment
Scaling to multi-agent architectures, security, and production deployment.

## 🛠️ Tech Stack & Requirements

- **Language:** Python 3.10+
- **Core AI Libraries:** `openai`, `tiktoken`, `sentence-transformers`, `mcp`
- **Data & Vector Stores:** `faiss-cpu`, `chromadb`, `scipy`
- **Web & APIs:** `fastapi`, `requests`, `beautifulsoup4`
- **LLM Access:** An active API key from an LLM provider is required for lab exercises.
